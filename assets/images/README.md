# assets/images

Drop approved photographs here using the exact filenames listed in
`PHOTO-GUIDE.md` (at the repository root). The build swaps each wireframe
placeholder for the real image automatically.

Folders: `hero/`, `about/`, `care/`, `office/`, `details/`, `video/`.
`og/og-default.png` is the social-sharing preview image (no photograph of
Dr. Rainey is used in it).
